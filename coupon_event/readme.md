# 쿠폰 시스템

## 쿠폰 시스템 요구사항 
### 쿠폰
- 쿠폰은 고정 할인 금액과 할인율을 적용해주는 쿠폰으로 구성된다.
- 각 쿠폰은 타입을 가지는데 생일, 웰컴, 선착순 쿠폰으로 분류된다. 
- 이 외에도 전략적으로 쿠폰 타입을 구분하여 적용할 수 있다.

### 쿠폰 적용
- 쿠폰은 적용 가능한 상품에 대해 적용할 수 있다.
- 쿠폰의 만료기간이 지나면 사용할 수 없다.
- 쿠폰이 이벤트로 발행된 경우, 이벤트 기간이 지나면 사용할 수 없다.
- 쿠폰은 중복 적용이 불가능하다.

### 쿠폰 발행
- 쿠폰은 이벤트, 생일, 웰컴, 선착순 등 다양한 방법으로 발행할 수 있다.
- 웰컴 쿠폰은 회원가입 시 자동으로 1개 발행된다. (만료기한은 무기한)
- 생일 쿠폰은 회원의 생일에 자동으로 발행된다. (만료기한은 발급일로부터 1년이다.)
- 선착순 쿠폰은 선착순으로 발행되며, 발행 수량이 정해져 있다.

## 쿠폰 API
### 쿠폰 조회
- 외부에서 쿠폰을 조회할 수 있다.
- 쿠폰의 유효성을 확인해 결과를 반환한다.
- 사용자가 가진 쿠폰을 조회할 수 있다.
  - 사용자가 가진 쿠폰은 만료된 쿠폰을 제외하고 반환한다.
  - 사용자가 가진 쿠폰은 쿠폰의 만료일을 기준으로 정렬하여 반환한다.

### 쿠폰 발행
- 유저에게 쿠폰을 발행할 수 있다.
- 이벤트 타입을 지정하여 쿠폰을 발행할 수 있다.
  - 선착순
  - 생일
  - 웰컴
  - 기타 이벤트
